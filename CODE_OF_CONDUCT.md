# Code of conduct

## Our commitment

We want this project to be welcoming, respectful, and useful to everyone who
contributes, reports a problem, or asks a question.

## Expected behavior

- Be considerate, constructive, and specific.
- Explain disagreement with evidence and curiosity.
- Respect different experience levels, backgrounds, and communication styles.
- Keep feedback focused on the work, not the person.
- Protect private information shared accidentally in an issue or pull request.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, sexualized
behavior, deliberate disclosure of private information, and disruptive
bad-faith conduct are not acceptable.

## Enforcement

Maintainers may edit, remove, close, or restrict participation in content that
violates this code. Serious or repeated violations may result in a temporary or
permanent ban from project spaces.

Report conduct concerns privately through the repository maintainer's GitHub
profile rather than posting sensitive details.
